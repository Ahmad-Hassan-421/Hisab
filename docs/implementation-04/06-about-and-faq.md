# About and frequently asked questions

About Hisab shows the installed version and build, credits Hantalyze, and explains what a Hisab measures. Settings opens both About and the FAQ. Sign-in and recovery also link to the FAQ so users can read it before signing in. The FAQ answers questions using the current ledger, invitation, profile, recovery, and update workflows. It uses expandable questions that announce whether each answer is open.

The Hisab repository has public issues enabled. The app links there for general support and tells users to keep credentials and ledger details out of public posts. About also links to the Privacy Policy introduced in Phase 7. [Hisab Issues](https://github.com/Ahmad-Hassan-421/Hisab/issues)

The Android build, unit tests and lint passed. C51 instrumentation opened Help from sign-in, verified FAQ expand and collapse accessibility states, navigated to About, and checked the creator, installed version, and GitHub support control.
